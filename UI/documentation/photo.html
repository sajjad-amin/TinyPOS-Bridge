Dithering & Edge Sharpening
Thermal Halftoning vs. Standard Black & White

Thermal printers cannot print shades of gray — each micro-pin can only burn solid black or leave paper white. Standard thresholding produces ugly, blotchy photos where faces turn black. The Photo Studio API uses error-diffusion dithering and unsharp-mask spatial edge filtering to distribute micro-dots smoothly, rendering natural skin tones, soft gradients, and crisp details.

POST /api/print/photo
Multipart / Form-Data

Uploads an image file and renders it with fine-tuned halftoning, tone curve calibration, and spatial edge enhancement.

Quality Presets Overview
• Portrait / Face: Lifts midtone shadows (+8% brightness) and uses smooth error diffusion so facial skin doesn't darken into blotches.
• Crisp & Detailed: Boosts unsharp-masking to 200% for fine hair, eyelashes, eyes, and intricate jewelry.
• Balanced / Landscape: Neutral curve preserving distant horizon lines, trees, and sky gradients.
• High Contrast: Punches black levels for logos, line illustrations, and ink drawings.
• Retro Halftone: 8x8 Bayer ordered matrix mimicking vintage newspaper printing.

<?php
use Illuminate\Support\Facades\Http;

$apiKey = 'sk_live_your_api_key_here';
$baseUrl = '{{ request_url_base }}';
$photoPath = '/path/to/portrait.jpg';

$response = Http::withHeaders([
    'X-API-Key' => $apiKey,
])->attach(
    'file', file_get_contents($photoPath), 'portrait.jpg'
)->post("{$baseUrl}/api/print/photo", [
    'preset'      => 'portrait',    // 'portrait', 'sharp', 'balanced', 'high_contrast', 'halftone'
    'dither_algo' => 'floyd',       // 'floyd', 'atkinson', 'bayer'
    'sharpness'   => 1.2,           // Unsharp-mask edge boost
    'contrast'    => 1.15,          // Optional contrast multiplier
    'brightness'  => 1.08,          // Optional shadow lift
    'strength'    => 7,             // Thermal darkness (1-7)
    'immediate'   => true,          // 1-step direct print
    'keepjob'     => false,         // Database bloat protection
]);

$jobId = $response->json('job_id');
echo "Photo Job ID: {$jobId}\n";
