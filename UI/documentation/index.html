Authentication & Security

All requests under /api/* require authentication via your API Key (passed in the X-API-Key header or ?api_key= query parameter for media streams). Requests with missing or invalid keys return 403 Forbidden.

API Documentation Sections
QR Code API

Thermal QR printing, multilingual headers/footers, and high-speed PNG streaming for <img> tags.
Photo Studio API

High-fidelity 1-bit halftoning (Floyd-Steinberg, Atkinson, Bayer), 5 quality presets, and unsharp masking.
Invoices & PDFs

PDF receipt rendering, margin auto-cropping, and 80mm/A4 zoom auto-scaling to 384 dots.
Multilingual Text API

100% universal living language support: Bengali, Arabic, Hindi, CJK, English, and Emojis mixed seamlessly.
Job Control & Status

Immediate print abort, job cancellation, hardware connectivity status probe, and preview raster fetching.

Parameters & Options Reference
QR Code APIs (/api/print/qr & /api/qr/generate)
  • text / content (string, required): The URL, invoice link, or raw string data to encode.
  • header (string, optional): Multilingual header text printed centered above the QR code.
  • footer (string, optional): Multilingual footer text printed centered below the QR code.
  • qr_size / size (int, default: 260, range: 64–384): Pixel dimension of the QR code square.
  • strength (int 1–7, default: 7): Thermal pulse darkness.
  • immediate (bool, default: true): Print immediately in background.
Photo Studio API (/api/print/photo)
  • file (file, required): Multipart image file (JPG, PNG, WebP).
  • preset (string, default: portrait): Quality preset (portrait, sharp, balanced, high_contrast, halftone).
  • dither_algo (string): Algorithm override: floyd, atkinson, or bayer.
  • sharpness (float, default: 1.2): Unsharp-mask spatial edge sharpening filter (0.0 to 3.0).
  • contrast (float, optional): Dynamic range curve multiplier (e.g. 1.15).
  • brightness (float, optional): Shadow tone lift multiplier (e.g. 1.08).
Document & Invoice API (/api/print/raw)
  • file (file, required): PDF or Image document.
  • scale (float, default: 1.0): Zoom multiplier (1.25 = +25% zoom for 80mm receipts).
  • autocrop (bool, default: true): Auto-trims white margins to maximize text width.
  • strength (int 1–7, default: 7): Thermal burning intensity.
Text & General Execution Options
  • text (string, required on /api/print/text): Multilingual text (all world scripts + emojis).
  • font_size (int, default: 22): Font size in points (14–48).
  • immediate (bool, default: true): Direct 1-Step printing without confirmation.
  • keepjob / keep_job (bool, default: false): SQLite database bloat protection. When false, records are temporary and purged after 5m. Set true to keep permanently in history.

import requests

api_key = 'sk_live_your_api_key_here'
base_url = '{{ request_url_base }}'
headers = {'X-API-Key': api_key}

# 1. Direct 1-Step Thermal QR Code Print
qr_res = requests.post(f"{base_url}/api/print/qr", headers=headers, json={
    "text": "https://sajjadamin.com/pay/101",
    "header": "TABLE #5 • বিল ৳৪৫০.০০",
    "footer": "Scan to Pay Online",
    "qr_size": 260,
    "immediate": True,
})
print("QR Job ID:", qr_res.json().get("job_id"))

# 2. High-Quality Photo Print
with open("portrait.jpg", "rb") as f:
    photo_res = requests.post(
        f"{base_url}/api/print/photo",
        headers=headers,
        files={"file": f},
        data={"preset": "portrait", "dither_algo": "floyd", "immediate": "true"}
    )
print("Photo Job ID:", photo_res.json().get("job_id"))

# 3. Print Multilingual Text Receipt
text_res = requests.post(f"{base_url}/api/print/text", headers=headers, json={
    "text": "RESTAURANT EXPRESS 🍕\nTotal: ৳৪৫০.০০",
    "font_size": 22,
    "immediate": True,
})
print("Text Job ID:", text_res.json().get("job_id"))

# 4. Feed Paper Roll
feed_res = requests.post(f"{base_url}/api/print/feed", headers=headers)
print("Feed Paper Result:", feed_res.json())
