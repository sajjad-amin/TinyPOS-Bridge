Thermal Printer Integration Guide
Authentication & Security

All requests under /api/* require your API Key to be sent via the X-API-Key HTTP header. Requests with missing or invalid keys return 403 Forbidden.

Core API Endpoints
Base URL
{{ request_url_base }} (Auto-detected)
Headers
X-API-Key: <your_api_key>
Accept: application/json
Endpoints
POST /api/print/raw Upload PDF/Image invoice. Prints immediately in 1-step! (Supports scale, autocrop, immediate)
POST /api/print/photo Photo Studio Print: High-fidelity 1-bit thermal halftoning for photos and artwork with quality presets (preset, dither_algo, sharpness, contrast, brightness, strength)
POST /api/print/text Print formatted text in 1-step! (Supports font_size, strength, immediate)
POST /api/print/qr Print Thermal QR Code: High-contrast thermal QR code with optional header & footer text (supports content / text, header, footer, qr_size, strength)
GET/POST /api/qr/generate Direct QR Generator: Streams a 384px PNG QR code directly from text/URL for embedding in <img> tags or reports (no auth required).
POST /api/print/stop Immediate Stop: Aborts whatever print job is currently actively streaming to the printer!
DELETE /api/print/cancel/{id} Cancel a pending queued job or halt an active printing job by ID.
POST /api/print/confirm/{id} Optional: Manually confirm a pending print job (if immediate=false was used)
GET /api/status Probe thermal printer online/offline status (reports is_printing: true if busy)
Parameters & Options
  • immediate (boolean, default: true): Direct 1-Step Execution! When true, the job prints immediately in the background without needing a secondary /confirm request.
  • preset (string, default: portrait): Quality preset for /api/print/photo (portrait for soft skin tones, sharp for eyes & hair detail, balanced for landscapes, high_contrast for logos, halftone for vintage newsprint).
  • dither_algo (string): Halftoning algorithm for /api/print/photo (floyd for Floyd-Steinberg error diffusion, atkinson for crisp Apple Mac highlights, bayer for 8x8 ordered matrix).
  • sharpness (float, default: 1.2): Unsharp-mask spatial edge enhancement filter (0.0 to 3.0) applied before halftoning to make thermal photos razor-sharp.
  • keepjob / keep_job (boolean, default: false): Database Bloat Protection! By default, jobs are temporary and purged from SQLite after 5 minutes so high-volume POS invoicing doesn't bloat disk space. Pass keepjob=true or keep_job=true to permanently save the job and preview raster in history.
  • scale (float, default: 1.0): Zoom/Scale multiplier (e.g. 1.25 = +25% zoom, 1.5 = +50% zoom). Expands 80mm or A4 receipts to make fonts crisp and readable on 57mm paper!
  • autocrop (boolean, default: true): Automatically strips empty white borders and margins so receipt text fills the full 384-dot width.
  • strength (integer 1-7, default: 7): Thermal burning energy and pulse pacing. Level 7 maximizes darkness and thickens text strokes for weak or aged thermal paper rolls.

<?php
use Illuminate\Support\Facades\Http;

$apiKey = 'sk_live_your_api_key_here';
$baseUrl = '{{ request_url_base }}';

// 1. Direct 1-Step QR Code Print
$qrRes = Http::withHeaders(['X-API-Key' => $apiKey])
    ->post("{$baseUrl}/api/print/qr", [
        'text'      => 'https://pos.sayem.com/pay/inv_1042',
        'header'    => 'SCAN TO PAY ৳৪৫০.০০',

# 1. Print Thermal QR Code directly to printer

  -H "X-API-Key: sk_live_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{"text": "https://pos.sayem.com/pay/101", "header": "TABLE #5", "footer": "Scan to Pay", "qr_size": 260, "immediate": true}'

# 2. Directly Generate/Download 384px QR Code PNG (no API key required)
curl -o qr.png "{{ request_url_base }}/api/qr/generate?text=https://pos.sayem.com&header=ORDER+101&size=260"

# 3. High-Quality Photo Print (Floyd-Steinberg / Atkinson Dithering & Unsharp Mask)
curl -X POST {{ request_url_base }}/api/print/photo \
  -H "X-API-Key: sk_live_your_api_key_here" \
  -F "file=@portrait.jpg" \
  -F "preset=portrait" \
  -F "dither_algo=floyd" \
  -F "sharpness=1.2" \
  -F "strength=7" \
  -F "immediate=true"

# 4. Print Invoice PDF or Receipt Document

  -F "scale=1.25" \
