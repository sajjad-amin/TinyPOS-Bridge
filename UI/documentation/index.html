Thermal Printer Integration Guide
Authentication & Security

All requests under /api/* require your API Key to be sent via the X-API-Key HTTP header. Requests with missing or invalid keys return 403 Forbidden.

Core API Endpoints
Base URL
{{ request_url_base }} (Auto-detected)
Headers
X-API-Key: <your_api_key>
Accept: application/json
Endpoints
POST /api/print/raw Upload PDF/Image. By default prints immediately in 1-step! (Supports scale, autocrop, immediate)
POST /api/print/text Print formatted text in 1-step! (Supports font_size, strength, immediate)
POST /api/print/stop Immediate Stop: Aborts whatever print job is currently actively streaming to the printer!
DELETE /api/print/cancel/{id} Cancel a pending queued job or halt an active printing job by ID.
POST /api/print/confirm/{id} Optional: Manually confirm a pending print job (if immediate=false was used)
GET /api/status Probe thermal printer online/offline status (reports is_printing: true if busy)
Parameters & Options
  • immediate (boolean, default: true): Direct 1-Step Execution! When true, the job prints immediately in the background without needing a secondary /confirm request.
  • keepjob / keep_job (boolean, default: false): Database Bloat Protection! By default, jobs are temporary and purged from SQLite after 5 minutes so high-volume POS invoicing doesn't bloat disk space. Pass keepjob=true or keep_job=true to permanently save the job and preview raster in history.
  • scale (float, default: 1.0): Zoom/Scale multiplier (e.g. 1.25 = +25% zoom, 1.5 = +50% zoom). Expands 80mm or A4 receipts to make fonts crisp and readable on 57mm paper!
  • autocrop (boolean, default: true): Automatically strips empty white borders and margins so receipt text fills the full 384-dot width.
  • strength (integer 1-7, default: 7): Thermal burning energy and pulse pacing. Level 7 maximizes darkness and thickens text strokes for weak or aged thermal paper rolls.
  • font_size (integer, default: 22): Direct text font size (12 to 60pt) for /api/print/text.
Code Examples (Direct 1-Step Printing)
<?php

// Direct 1-Step Print in Laravel (No /confirm needed!)
use Illuminate\Support\Facades\Http;

$apiKey = 'sk_live_your_api_key_here';
$baseUrl = '{{ request_url_base }}';

// Example 1: Print Receipt PDF immediately (temporary, purged after 5m)
$response = Http::withHeaders([
    'X-API-Key' => $apiKey,
])->attach(
    'file', file_get_contents($pdfPath), 'receipt.pdf'
)->post("{$baseUrl}/api/print/raw", [
    'immediate' => 'true',  // Prints immediately!
    'scale'     => 1.25,    // 1.25x zoom for 80mm receipts, 1.5x for A4
    'autocrop'  => 'true',  // Trims empty white margins
    'strength'  => 7,       // 1-7: max thermal burn darkness
    'keepjob'   => 'false',  // Set 'true' only if you want to permanently keep in SQLite
]);

$jobId = $response->json('job_id'); // Already printing!

// Example 2: Print Plain Text Receipt immediately
$textRes = Http::withHeaders([
    'X-API-Key' => $apiKey,
])->post("{$baseUrl}/api/print/text", [
    'text'      => "ACME STORE\nInvoice #1042\nTotal: \$45.00",
    'font_size' => 24,
    'strength'  => 7,
    'immediate' => true,    // Prints immediately!
    'keepjob'   => false,   // Temporary job, removed after 5 minutes
]);

# 1. Direct 1-Step Text Print (Temporary by default, removed after 5m)
curl -X POST {{ request_url_base }}/api/print/text \
  -H "X-API-Key: sk_live_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{"text": "SAMPLE INVOICE\nItem 1: $10.00\nTotal: $10.00", "font_size": 22, "immediate": true, "keepjob": false}'

# 2. Direct 1-Step File Upload Print (PDF or Image, preserved permanently in DB)
curl -X POST {{ request_url_base }}/api/print/raw \
  -H "X-API-Key: sk_live_your_api_key_here" \
  -F "file=@receipt.pdf" \
  -F "scale=1.25" \
  -F "autocrop=true" \
  -F "immediate=true" \
  -F "keepjob=true"

# 3. Check Printer Status
curl -X GET {{ request_url_base }}/api/status \
  -H "X-API-Key: sk_live_your_api_key_here"

const apiKey = 'sk_live_your_api_key_here';
const baseUrl = '{{ request_url_base }}';

// Direct 1-Step Print Receipt (immediate: true, keepjob: false)
const res = await fetch(`${baseUrl}/api/print/text`, {

    text: "RECEIPT #101\nWidget A: $20.00\nTotal: $20.00",
    font_size: 22,

  })
});
const data = await res.json();
console.log('Dispatched Job ID:', data.job_id);
