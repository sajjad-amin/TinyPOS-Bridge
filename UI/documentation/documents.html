Invoice & Document Printing API
Direct 1-step printing for PDF invoices, payment receipts, barcode labels, and graphics
PDF & Image Engine
Receipt Auto-Cropping & 80mm/A4 Auto-Scaling

Standard POS invoices are often designed for 80mm wide desktop printers or A4 paper. TinyPOS automatically removes empty white margins (autocrop=true) and supports zoom multipliers (scale=1.25 or 1.5) to expand receipt fonts across the 57mm (384-dot) paper width for razor-sharp legibility.

POST /api/print/raw
Multipart / Form-Data

Uploads an invoice PDF or document image for immediate 1-step rasterization and thermal printing.

Form-Data Parameters
FieldTypeDefaultDescription
filefilerequiredPDF document, PNG, JPG, or WebP invoice file
scalefloat1.0Zoom multiplier (e.g. 1.25 for 80mm receipts, 1.5 for A4 invoices)
autocropbooltrueAutomatically trims white whitespace margins around content
strengthint7Thermal burn pulse energy (1 to 7)
immediatebooltrueExecutes immediately in background (set false for 2-step manual confirmation)
keepjob / keep_jobboolfalseDatabase bloat protection: when false, SQLite records are purged after 5m

<?php
use Illuminate\Support\Facades\Http;

$apiKey = 'sk_live_your_api_key_here';
$baseUrl = '{{ request_url_base }}';
$pdfPath = '/path/to/invoice_1042.pdf';

// Direct 1-Step Invoice PDF Print
$response = Http::withHeaders([
    'X-API-Key' => $apiKey,
])->attach(
    'file', file_get_contents($pdfPath), 'invoice.pdf'
)->post("{$baseUrl}/api/print/raw", [
    'scale'     => 1.25,   // Zoom 1.25x for 80mm receipts
    'autocrop'  => 'true',  // Strip empty whitespace borders
    'strength'  => 7,       // Maximum thermal darkness
    'immediate' => 'true',  // Print immediately in background
    'keepjob'   => 'false', // Auto-purged from SQLite after 5m
]);

$jobId = $response->json('job_id');
echo "Invoice Job Queued: {$jobId}\n";

# Upload and print PDF invoice directly

  -F "file=@invoice.pdf" \
  -F "scale=1.25" \
  -F "autocrop=true" \
  -F "strength=7" \
  -F "immediate=true"
