QR Code Printing & Direct Image Generator API
High-contrast thermal QR codes with centered multilingual headers and footers
Thermal Optimized
Direct Printing or Zero-Auth PNG Streaming

TinyPOS offers two QR capabilities: (1) Print Directly: Send POST /api/print/qr with your API key to print a thermal QR code with optional multilingual headers and footers. (2) Stream Image: Request GET /api/qr/generate?text=... with no authentication required to generate a 384px monochrome PNG on-the-fly for web <img> tags or invoice templates.

POST /api/print/qr
Requires API Key

Renders and prints a QR code directly to the thermal receipt printer.

Request Headers
X-API-Key: <your_api_key>
Content-Type: application/json
JSON Payload Parameters
FieldTypeDefaultDescription
text / contentstringrequiredData, URL, or invoice string to encode
headerstringnullHeader text printed centered above QR (all languages + emojis)
footerstringnullFooter text printed centered below QR
qr_size / sizeint260QR dimension in dots (64 to 384)
strengthint7Print burning darkness (1 to 7)
immediatebooltrueExecute immediately in background
keepjobboolfalsePreserve job record in SQLite database
Success Response (200 OK) 
{
  "job_id": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
  "status": "printing",
  "immediate": true,
  "width": 384,
  "height": 320,
  "preview_url": "/api/print/preview/9b1deb4d..."
}
GET / POST /api/qr/generate
No Auth Required

Streams a live 384px monochrome PNG QR code. Ideal for embedding in web <img> tags or downloadable reports.

Query Parameters (GET) or JSON Body (POST)
ParameterTypeDefaultDescription
text / contentstringrequiredTarget text or URL to encode
headerstringnullOptional top banner text
footerstringnullOptional bottom banner text
size / qr_sizeint260QR size in dots (64 to 384)
strengthint7Thermal print pulse pacing
HTML Image Tag Embed Example
<img src="{{ request_url_base }}/api/qr/generate?text=https://pos.sayem.com/pay/101&header=TABLE+5&size=260" alt="Thermal QR Code" />
cURL Save Example 
curl -o qr.png "{{ request_url_base }}/api/qr/generate?text=https://pos.sayem.com&header=ORDER+99&size=260"

<?php
use Illuminate\Support\Facades\Http;

$apiKey = 'sk_live_your_api_key_here';
$baseUrl = '{{ request_url_base }}';

// 1. Direct 1-Step Thermal QR Code Print
$response = Http::withHeaders([
    'X-API-Key' => $apiKey,
])->post("{$baseUrl}/api/print/qr", [
    'text'      => 'https://pos.sayem.com/pay/inv_1042',
    'header'    => 'SCAN TO PAY ৳৪৫০.০০',  // Bangla, Arabic, English, Emojis
    'footer'    => 'Table #12 • TinyPOS',
    'qr_size'   => 260,
    'strength'  => 7,
    'immediate' => true,
]);

$jobId = $response->json('job_id');

// 2. Direct QR PNG Image Stream (no API key required)
$qrPngBytes = Http::get("{$baseUrl}/api/qr/generate", [
    'text'   => 'https://pos.sayem.com',
    'header' => 'ORDER #99',
    'size'   => 260,
])->body();

# 1. Print Thermal QR Code directly to printer
curl -X POST {{ request_url_base }}/api/print/qr \
  -H "X-API-Key: sk_live_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "https://pos.sayem.com/pay/101",
    "header": "TABLE #5 • বিল ৳৪৫০.০০",
    "footer": "Scan to Pay Online",
    "qr_size": 260,
    "strength": 7,
    "immediate": true
  }'

# 2. Directly Download 384px QR Code PNG (no API key required)
curl -o qr.png "{{ request_url_base }}/api/qr/generate?text=https://pos.sayem.com&header=ORDER+101&size=260"

const apiKey = 'sk_live_your_api_key_here';
const baseUrl = '{{ request_url_base }}';

// 1. Direct 1-Step QR Code Print
const res = await fetch(`${baseUrl}/api/print/qr`, {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-API-Key': apiKey
  },
  body: JSON.stringify({
    text: "https://pos.sayem.com/order/54",
    header: "TABLE 5",
    footer: "Scan to Pay",
    qr_size: 260,
    strength: 7,
    immediate: true
  })
});
const data = await res.json();
console.log('QR Job Dispatched:', data.job_id);

// 2. Dynamic Image Element Embed (No Auth needed)
const img = document.createElement('img');
img.src = `${baseUrl}/api/qr/generate?text=${encodeURIComponent('https://pos.sayem.com')}&header=TABLE+5&size=260`;
document.body.appendChild(img);
