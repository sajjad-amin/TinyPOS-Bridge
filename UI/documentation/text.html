TinyPOS bundles comprehensive Unicode fonts. Bengali (বাংলা), Arabic (العربية), Urdu (اردو), Hindi (हिन्दी), Chinese (中文), Japanese (日本語), Korean (한국어), Russian (Русский), Thai (ไทย), and all Emojis (🍕☕❤️) can be freely mixed on the same line without missing glyph boxes or broken ligatures.

POST /api/print/text
Requires API Key

Renders formatted multilingual receipt text with automatic line-wrapping and prints immediately in 1 step.

JSON Payload Parameters
FieldTypeDefaultDescription
textstringrequiredRaw receipt text. Use \n for line breaks. Supports all world languages and emojis.
font_sizeint22Font size in points (recommended: 20–26 for receipts)
strengthint7Thermal print darkness intensity (1 to 7)
immediatebooltrueExecutes immediately in background (set false for 2-step manual confirmation)
keepjob / keep_jobboolfalseDatabase bloat protection: when false, SQLite records are purged after 5m

    . "Mineral Water (500ml)    ৳২৫.০০\n"
    . "--------------------------------\n"
    . "সর্বমোট বিল / TOTAL     ৳২৮০.০০\n"
    . "ধন্যবাদ! আবার আসবেন ❤️\n"
    . "================================";

$response = Http::withHeaders([
    'X-API-Key' => $apiKey,
])->post("{$baseUrl}/api/print/text", [
    'text'      => $receiptText,
    'font_size' => 22,
    'strength'  => 7,
    'immediate' => true,
]);

$jobId = $response->json('job_id');
echo "Text Receipt Queued: {$jobId}\n";
