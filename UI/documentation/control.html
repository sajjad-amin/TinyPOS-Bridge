Job Control, Cancellation & Status APIs
Immediate print abort, job cancellation, hardware connectivity probe, and preview raster fetching
Job Lifecycle
Immediate Print Abort (Save Thermal Paper)

If a user accidentally prints a 100-page document or wrong invoice, calling POST /api/print/stop instantly halts the active Bluetooth transmission loop and cancels all pending packets within milliseconds, preventing wasted thermal paper rolls.

POST /api/print/stop
Requires API Key

Aborts whatever print job is currently streaming over Bluetooth to the printer.

{
  "success": true,
  "message": "Immediate stop signal sent."
}
DELETE / POST /api/print/cancel/{job_id}
Requires API Key

Cancels a pending queued job or halts an active printing job matching job_id.

{
  "job_id": "4f9b8c12-3456-789a-bcde-0123456789ab",
  "status": "cancelled",
  "message": "Job cancelled."
}
GET /api/status
Requires API Key

Probes printer BLE connection status and checks if the print head is actively printing (is_printing: true).

{
  "connected": true,
  "device_name": "Bainiu X6",
  "is_printing": false,
  "battery_level": 85
}
GET /api/print/preview/{job_id}
Requires API Key

Fetches the exact 384px-wide 1-bit monochrome PNG image generated for the print job from SQLite.

Returns: image/png binary stream
POST /api/print/feed (alias: /api/printer/feed)
Requires API Key

Advances / feeds the thermal receipt roll by standard line feed steps, allowing the user to cleanly tear off invoices or receipts.

{
  "success": true,
  "message": "Feed paper command sent to thermal printer."
}

use Illuminate\Support\Facades\Http;

$apiKey = 'sk_live_your_api_key_here';
$baseUrl = '{{ request_url_base }}';

// 1. Feed / Advance Paper
$feedRes = Http::withHeaders(['X-API-Key' => $apiKey])
    ->post("{$baseUrl}/api/print/feed");

// 2. Immediate Print Abort
$stopRes = Http::withHeaders(['X-API-Key' => $apiKey])
    ->post("{$baseUrl}/api/print/stop");

// 3. Cancel Job by ID
$cancelRes = Http::withHeaders(['X-API-Key' => $apiKey])
    ->delete("{$baseUrl}/api/print/cancel/{$jobId}");

// 4. Probe Hardware & Busy Status
$status = Http::withHeaders(['X-API-Key' => $apiKey])
    ->get("{$baseUrl}/api/status")->json();

if ($status['is_printing']) {
    echo "Printer is currently busy.\n";
}
